# 🚗 Cab Booking System

This is a Python-based Cab Booking System that simulates real-world cab booking functionality.

## 🔹 Features
- User can enter pickup and drop locations
- Fare calculation based on distance
- Booking confirmation system
- Simple and user-friendly interface

## 🛠 Technologies Used
- Python
